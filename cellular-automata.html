< Back A cellular automaton consists of a grid of 'cells' which can be in multiple different states, and a set of rules for how to change those cells' states. Each time the set of rules is applied, a 'generation' is said to have passed, and upon repeatedly advancing generations, interesting patterns can form. Further reading about cellular automata: https://conwaylife.com/wiki/Cellular_automaton
